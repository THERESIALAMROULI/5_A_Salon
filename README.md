# Kelompok 5 - Pemrograman Berbasis Platform A

## 💇‍♂️ Deskripsi Proyek
Proyek ini adalah aplikasi **Atma Barber Shop** yang dibangun menggunakan **Flutter** untuk memenuhi tugas mata kuliah Pemrograman Berbasis Platform A. Aplikasi ini menyediakan antarmuka yang modern (dengan tema gelap dan emas) dan berbagai fitur yang memungkinkan pengguna untuk melihat layanan potong rambut, melihat profil tukang cukur, serta mengelola akun pribadi mereka.

## ✨ Fitur Utama

Aplikasi ini memiliki beberapa halaman utama dengan fungsionalitas sebagai berikut:

### 1. Autentikasi Pengguna (Login & Register)
- Pengguna baru dapat mendaftarkan akun.
- Pengguna yang sudah memiliki akun dapat melakukan login ke dalam aplikasi.

### 2. Beranda (Home Dashboard)
- **Promo & Diskon**: Menampilkan banner penawaran seperti "Launching Discount" untuk pelanggan.
- **Kategori Layanan**: Pilihan layanan cepat seperti *Haircut, Treatment, Mustache, Beard, Shaving,* dan *Coloring*.
- **Daftar Barber (Tukang Cukur)**: Menampilkan daftar profil tukang cukur yang sedang tersedia beserta keahlian mereka (misal: *Sir Sapling the III, Sir Leaf the II*) dan rating kepuasan pelanggan.

### 3. Profil Pengguna (User Profile)
- **Informasi Akun**: Menampilkan nama dan kontak pengguna (email, nomor telepon).
- **Ubah Foto Profil**: Terintegrasi dengan perangkat keras (kamera dan galeri) untuk mengambil atau memilih gambar profil baru.
- **Menu Pengaturan**: Terdapat navigasi terstruktur untuk mengedit profil, melihat notifikasi, riwayat transaksi, voucher, kontak bantuan, serta opsi *Logout*.

## 🛠️ Teknologi dan Paket yang Digunakan
- **Framework**: Flutter
- **Bahasa Pemrograman**: Dart
- **Package Utama**:
  - `flutter/material.dart` - Untuk komponen UI standar Material Design.
  - `image_picker` - Untuk mengakses kamera dan galeri (pada fitur ubah foto profil).

## 🚀 Cara Menjalankan Proyek

1. Pastikan Anda telah menginstal [Flutter SDK](https://flutter.dev/docs/get-started/install) (direkomendasikan versi 3.5.3 atau yang lebih baru).
2. Clone atau unduh repositori proyek ini.
3. Buka terminal atau command prompt dan arahkan ke direktori proyek (`5_A_Salon`).
4. Jalankan perintah berikut untuk mengunduh semua dependensi:
   ```bash
   flutter pub get
   ```
5. Jalankan aplikasi pada perangkat atau emulator yang terhubung:
   ```bash
   flutter run
   ```
